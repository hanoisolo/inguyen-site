# Conventions

## Stack
- Plain static HTML/CSS/JS. No build step, no npm, no frameworks, no CDNs, no external fonts or icon libraries. Served by GitHub Pages from `main`, root `/`.
- `CNAME` contains `www.inguyen.ca`. `.nojekyll` present. Never edit either.

## Layout
```
index.html               single page, all sections
404.html                 (segment 3)
assets/css/tokens.css    design tokens only (custom properties)
assets/css/components.css primitives: layout, buttons, tags, badges, cards, section headings
assets/css/sections.css  section-specific styles (header, hero, games, projects, about, footer)
assets/js/main.js        small progressive enhancements; page works without it
assets/img/              portrait (don-480/800 .webp+.jpg), og.jpg, favicons
assets/games/<slug>.webp game thumbnails 640x400
docs/                    spec, conventions, segments, decisions
tests/check_site.py      automated gate (python3, stdlib only)
```
CSS load order in `<head>`: tokens.css, components.css, sections.css. One JS file, `defer`.

## Primitives (components.css)
`.container` (max-width var(--container), side padding) · `.section` (vertical padding) · `.section-head` (eyebrow `.eyebrow`, `h2`, `.lead`) · `.btn`, `.btn--primary`, `.btn--ghost` · `.tag` (chip) · `.badge`, `.badge--warn`, `.badge--soon` · `.card`, `.card__media`, `.card__body`, `.card__title`, `.card__text`, `.card__tags`, `.card__actions`, `.card--featured`, `.card--soon`, `.card--repo` · `.grid` (auto responsive: 1/2/3 cols at <640 / ≥640 / ≥1024) · `.visually-hidden` · `.skip-link`.
Global: box-sizing border-box, `body` uses tokens, `a` colors, `:focus-visible` ring `2px solid var(--accent-2)` offset 3px, `img { max-width:100%; height:auto; display:block }`, `html { scroll-behavior:smooth }`.
A single `@media (prefers-reduced-motion: reduce)` block per CSS file turns off animations/transitions and smooth scroll.

## Naming
BEM-ish: block `.card`, element `.card__title`, modifier `.card--featured`. Section ids: `top, games, projects, about`. Kebab-case files and slugs. State classes `is-*`.

## Content
Content lives as semantic HTML in `index.html` (no runtime JSON fetch) so it works without JS and is indexable. Copy for each card comes verbatim from docs/spec.md §3–§5.

## Don't
- Don't add frameworks, CDNs, analytics, cookies, web fonts, forms, or email addresses.
- Don't use fake/template projects. Only Don's real games and repos.
- Don't nest links inside links; don't make whole cards clickable via JS.
- Don't touch CNAME, .nojekyll, docs/, tests/, or assets/img, assets/games (images are pre-generated by Forge).
- Don't commit or push (Forge does that).
